# Badge

Le badge affiche un statut en un mot : paiement, présence, inscription.

- Tons : `success` (Payé, Présent), `warning` (En attente, Retard), `danger` (Impayé, Absent), `info` (Nouveau), `gold` (Diplômé, Premium), `neutral` (Brouillon).
- Fond `-soft`, texte de la couleur d'état ; `caption` en capitales, `radius-pill`.
- `dot` ajoute une pastille ; le mot reste obligatoire (jamais la couleur seule).

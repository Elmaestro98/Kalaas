# Input

Champ de saisie Kalaas avec libellé, texte d'aide et message d'erreur.

- Fond `surface-200`, bordure `border`, `radius-sm`, Poppins 15px ; libellé en `label`.
- Focus : bordure `gold-500` + halo `gold-100`. Erreur : bordure et message en `danger`, halo `danger-soft`.
- `required` ajoute un astérisque ; `error` remplace `hint`. Toujours un libellé visible, le placeholder n'est qu'un exemple (« 77 123 45 67 »).
- Accepte tous les attributs natifs (`type`, `value`, `onChange`…).

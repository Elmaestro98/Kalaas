# Card

La carte regroupe une information : un apprenant, une promotion, un indicateur du tableau de bord.

- Fond `surface-200`, bordure `border`, `radius-lg`, padding `space-6`, ombre `shadow-card`.
- `eyebrow` (sur-titre `overline` en `gold-700`), `title` (`h3`), `aside` (un badge ou un chiffre), `footer` (boutons alignés à droite).
- `accent` ajoute un filet `gold-500` en haut : réservé aux cartes mises en avant (indicateurs clés).
- Avec `onClick`, la carte devient cliquable et monte en `shadow-raised` au survol.

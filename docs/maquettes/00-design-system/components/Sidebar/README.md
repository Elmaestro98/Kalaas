# Sidebar

Barre latérale de l'application Kalaas : la présence la plus forte du bleu nuit.

- Fond `navy-900` dans les deux thèmes, largeur 248px ; nom « Kalaas. » en Poppins 700 avec le point en `gold-500` (en attendant le logo).
- Éléments : `label` 14px ; survol `navy-800` ; actif `navy-700` avec barre verticale `gold-500` et `aria-current="page"`.
- `count` affiche une pastille or (ex. paiements en retard). `sections` regroupe les liens sous un sur-titre.
- `footer` : nom de l'institut ou de l'utilisateur connecté.

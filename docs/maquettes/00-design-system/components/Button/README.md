# Button

Le bouton Kalaas déclenche une action ; `primary` pour l'action principale d'un écran, `gold` pour une mise en avant commerciale ou de réussite.

- Variantes : `primary` (fond `action`), `gold` (fond `gold-500`, texte `navy-900`), `secondary` (contour `border`), `ghost` (survol `gold-100`), `danger` (fond `danger`).
- Tailles : `sm` (tableaux), `md` (défaut), `lg` (écrans d'accueil, formulaires publics).
- Poppins 500, `radius-md`, padding `space-3`/`space-4`, focus `focus-ring`.
- Un seul `primary` ou `gold` par zone. Libellé = verbe + objet (« Inscrire l'apprenant »).
- Le consommateur fournit le libellé et le `onClick`.

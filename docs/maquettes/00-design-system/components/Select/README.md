# Select

Liste déroulante native habillée aux couleurs Kalaas, pour choisir une promotion, une formation ou un mode de paiement.

- Même habillage que `Input` (bordure, focus or, erreur `danger`) avec un chevron `ink-muted`.
- `options` : tableau de chaînes ou de `{ value, label }` ; `placeholder` ajoute une première option désactivée.
- Au-delà de ~15 options, préférer un champ de recherche.
